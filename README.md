# BarberStudio
Aplicacion android para una barberia
Link a figma: https://www.figma.com/design/IbGbjbG9icNPCR1d6Ot4xK/APP-BARBERIA?node-id=0-1&t=nqxxdZ8wgRNsYQl9-1

Requerimientos – App Barbería (Vista Cliente) 

1. Cuenta y acceso 

RF-01, Registrarse, El usuario crea una cuenta con nombre, email, teléfono y contraseña. 

RF-02, Iniciar sesión, El usuario ingresa con email y contraseña. 

RF-03, Cerrar sesión, El usuario cierra su sesión desde la app. 

2. Turnos 

RF-03, Solicitar turno, El usuario reserva un turno eligiendo servicio, peluquero, fecha y horario. Al confirmar, ve un resumen del turno. 

RF-05, Consultar historial de turnos, El usuario ve sus turnos próximos y pasados, con su estado (confirmado, cancelado, completado). 

RF-06, Cancelar turno, El usuario cancela un turno próximo. La app pide confirmación antes de cancelar. 

3. Catálogo 

RF-07, Consultar servicios, El usuario ve los servicios ofrecidos con precio y duración estimada: corte, barba, corte + barba, tintura. 

RF-08, Consultar productos, El usuario ve los productos a la venta con descripción y precio: cremas, pomadas, etc. 

4. Perfil y preferencias 

RF-10, Consultar información del usuario, El usuario ve sus datos personales: nombre, email, teléfono. 

RF-11, Modificar preferencias del usuario y datos, El usuario configura sus preferencias (ver detalle abajo). 

Preferencias (RF-11) 

Notificaciones: activar/desactivar recordatorios de turno y avisos de promociones. 

Anticipación del recordatorio: cuándo recibir el aviso (ej. 1 hora o 1 día antes). 

Canal de aviso: notificación push, email o WhatsApp. 

Peluquero favorito: se preselecciona al solicitar un turno. 

Servicio habitual: se preselecciona al solicitar un turno. 

Tema de la app: claro u oscuro.
